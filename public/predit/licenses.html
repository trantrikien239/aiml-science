TabICLv2 (the prediction model)

Predit's predictions come from TabICLv2, a pre-trained model for tabular data developed by the Soda team at Inria (github.com/soda-inria/tabicl). Predit runs the published TabICLv2 classifier weights, converted to the ONNX format, without retraining them.

The ONNX conversion currently used is bakshinghampalace/tabicl-classifier-v2-onnx (revision 098fb7be), published under the BSD-3-Clause license. Predit downloads these files unmodified from Hugging Face, in your browser, and checks their SHA-256 fingerprints before use.

forecast-web (data preparation code)

Part of Predit's in-browser data preparation (the TabICL preprocessing and ensembling steps) is adapted from forecast-web 1.0.0 (github.com/forge-veil/forecast-web), Copyright 2026 Vatsal Bakshi, licensed under the Apache License, Version 2.0.

Changes made by Predit: converted to a single plain JavaScript module that runs in a Web Worker; fixed size limits replaced by configurable limits; model fitting and prediction separated from the ONNX graph call so members and rows can be processed in chunks; timing and numerical checks added; regression (quantile) code removed, keeping classification only.

Predit loads the unmodified release files from the jsDelivr content delivery network (onnxruntime-web@1.31.1) and checks their SHA-256 fingerprints before use.
